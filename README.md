# SlimeTD-Data

슬라임 TD의 기획(정적) 데이터 원본 저장소. 서버(`SlimeTD-Server`)와 클라이언트(`SlimeTD`)는 이 저장소의 데이터를 받아 쓰고, 원본을 직접 고치지 않는다.

## 구성

| 경로 | 내용 |
|---|---|
| `Sheets/*.csv` | 데이터 원본. 기획자가 직접 편집한다 |
| `Sheets/README.md` | 시트별 열 설명, ID 규칙, 값 해석 규칙 |

## 편집 규칙

- CSV는 UTF-8이고 **1줄이 영문 열 이름**이다. 열 설명은 `Sheets/README.md`에 둔다
- 모든 데이터의 ID는 종류와 상관없이 겹치면 안 된다. 한 번 정한 ID는 바꾸지 않는다 (대역은 `Sheets/README.md`)
- 화면에 보이는 한글(이름, 설명)을 바꾸면 클라이언트에서 TMP 폰트 글자 정리를 다시 해야 한다

## 데이터 흐름 (예정)

```
Sheets/*.csv (원본)
   └─ 변환 도구: 검증(ID 중복, 참조 무결성, 값 범위) → 서버용/클라용 데이터 + 공용 C# 데이터 클래스 생성
        ├─ 서버: 시작 시 로드. 결과를 확정하는 기준
        └─ 클라: 표시와 예측용. 데이터 버전이 서버와 다르면 업데이트
```

현재는 원본만 옮겨 둔 상태다. 변환 도구, 웨이브/슬라임/GameConfig 시트(지금은 클라이언트 ScriptableObject에만 있음)는 이후 추가한다.
